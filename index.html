05 / PRODUCTION RCA

Incident → RCA → Prevention.

A practical example of how I approach production incidents.

Unexpected container CPU consumption

A production container showed abnormal CPU activity. Instead of treating the CPU graph as the root cause, the investigation moved down to the workload and process level.

Detect — Identify abnormal host/container CPU utilization.
Investigate — Correlate container metrics with processes, logs and runtime activity.
Isolate — Remove the suspicious workload safely and restore service.
Root cause — Investigate the image/dependency path and suspicious runtime process.
Prevent — Strengthen image scanning, runtime detection, monitoring and deployment controls.
